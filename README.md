# 🎧 SoundSync

**SoundSync** is a Flask-based web application that lets users connect their Spotify accounts, fetch their top tracks, and vote for their favorite songs on a live DJ dashboard. It's perfect for parties, cafes, or any shared music environment!

## 🚀 Features

- 🔐 Spotify OAuth authentication
- 🎵 Fetches users' top tracks using Spotify API
- 🗳️ Voting system with automatic vote decay over time
- 📸 QR code login support
- 🗂️ SQLite-based lightweight database
- ⏱️ Background scheduler to reduce outdated votes
